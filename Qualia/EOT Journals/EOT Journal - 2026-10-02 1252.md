## Things worth knowing

- **Teddy's authorization is per-action.** He approved "delete the test
  human and commit" for one specific commit; for the later changes I asked
  again rather than treating that as a standing go-ahead, and he answered
  each time. That matched how the commit rule is meant to work.
- **Gotcha I hit:** on this Windows box Python's `open().write()` defaults
  to cp1252. A patch script containing an em dash wrote a stray 0x97 byte
  into `db.py` and broke the import; fixed by replacing the byte with the
  UTF-8 em dash. Use `encoding='utf-8'` on every file write from now on.
  Also: a large bash heredoc with mixed quotes failed outright; writing the
  script to the scratchpad with the Write tool and running it was reliable.
- The lobby cannot exist on a brand-new db until the first human registers
  (rooms.created_by needs a real participant); `register_human` creates it
  then. A human who leaves the lobby is not pulled back in.
- Process lesson from the stray human: leftover test participants in the
  live db have real side effects once rules like "all humans join the
  lobby" exist. Clean up after live-db verification.
