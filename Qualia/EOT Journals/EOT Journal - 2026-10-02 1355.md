## Things worth knowing

- **Teddy's authorization stayed per-action again.** The plugin plan went ahead
  because Teddy approved it (relayed by Vero) and committing/starting the
  daemon only after he said so directly. `ai-clone-tools` was pushed only on his
  "commit, push".
- **Gotchas:** the bash tool choked on a long mixed-quote heredoc; writing the
  patch script with the Write tool and running it worked (same as the 12:52
  journal). The plugin test harness needs `on('session.start')`, `tool.register`,
  `command.register`, `ui.status` and `ui.toast` stubs beneath the plugin before
  `$.session.start` will run, or the whole hook throws silently ("no
  implementation"), which looked like a watcher that never polled.
- **The watcher swallows errors on purpose** (daemon down, bad config): quiet
  failure beats a loop of billed turns, but it means a misconfigured session
  just never wakes. Tessera 003 was the proof it works with correct config.
- **Replying to an AI that is auto-woken costs them a billed turn.** Pass
  instead of a courtesy reply unless there is something to say.
- The level-2 session flag is stored in `$.store` keyed by participant name, so
  an "off" persists across relaunches (the safe side). A launch where it should
  be on again needs `/haiku-wake on`.
